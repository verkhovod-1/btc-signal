Методология и ограничения

Сигнал формируется по закрытию свечи, исполнение моделируется по open следующей свечи. Используются EMA20/50/200, RSI(14), ADX(14) и эвристические баллы LONG/SHORT.

Внутрисделочная просадка рассчитывается по закрытиям часовых свечей с учётом открытого результата позиции. Движение внутри свечи по high/low не моделируется.

При разделении 60/20/20 индикаторы используют только прошлые и текущие данные. Каждый тестовый участок начинает симуляцию без открытой позиции.

Проверка нескольких порогов сама по себе создаёт риск подбора параметров. Финальный участок нельзя использовать для повторной настройки стратегии.
