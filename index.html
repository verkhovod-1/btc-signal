Издержки вычитаются из доходности сигнала. В качестве базового сравнения используется BTC без вычета торговых издержек. Это консервативное сравнение стратегии с рынком.

Как устроен тест

Сигнал: EMA20 выше EMA50, ADX14 выше 25, объём выше среднего за 20 свечей. Вход — открытие следующей часовой свечи. Доходность считается до закрытия свечи на горизонте 24, 48 или 72 часа.

История разделена хронологически: первые 80% — обучение, следующие 10% — проверка, последние 10% — финальный тест. Сделки, пересекающие границы участка, исключаются. Результаты финального теста не используются для подбора правил.

Ограничения

Почасовые сигналы могут быть зависимыми. Вариант A специально оставляет все сигналы для сравнения с прежней версией, поэтому его число сделок не равно числу независимых рыночных ситуаций. Варианты B и C сокращают повторные входы, но не гарантируют независимость результатов.

Просадка ниже рассчитана по последовательности доходностей сделок для соответствующего горизонта. Для варианта A сделки перекрываются, поэтому эта величина не является точной просадкой реализуемого портфеля. Тест не моделирует ликвидации, спред, задержки API и проскальзывание.
